# Album Covers Placeholder

This directory should contain the following album cover images:

- `pablo-honey.jpg` - 300x300px recommended
- `the-bends.jpg` - 300x300px recommended
- `ok-computer.jpg` - 300x300px recommended
- `kid-a.jpg` - 300x300px recommended

**Recommended specifications:**
- Format: JPG or PNG
- Size: 300x300px (will be displayed at 128x128px)
- Style: Pixel art or low-res for retro aesthetic

**Note:** These files are not included for copyright reasons.
Add your own images or use placeholder artwork.

The Music Player will show a fallback icon if images fail to load.

## How to Add Real Album Art

1. Obtain album cover images (respect copyright!)
2. Resize to 300x300px
3. Save as JPG with filenames matching above
4. Place in this `/public/covers/` directory
5. The Music Player will automatically display them

For a retro look, consider:
- Reducing color palette
- Adding pixelation effect
- Using dithering techniques
- Applying contrast/saturation filters in CSS
